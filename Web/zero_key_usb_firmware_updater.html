Instructions
  1. Connect your device and click Connect.
  2. Click Enter Bootloader (uses 1200 baud touch).
  3. Select your firmware file (.bin or .hex).
  4. Press Flash and wait until it finishes.
  5. Device will auto-reboot on success.
Bootloader Protocol (expected)

This page speaks a minimal, robust protocol over Web Serial to a SAMD21 bootloader. Implement (or adapt) these commands on the device side:

Host → Device
HELLO\n                      # probe, device replies "OK BOOT vX.Y"
ERASE APP\n                # mass erase application region
WRITE <addr> <len> <crc32>\n
<raw bytes… len…>
DONE\n                      # finalize, verify and reboot

Device → Host
OK BOOT vX.Y\n
OK ERASE\n
OK WRITE\n or ERR CRC\n
OK DONE\n

The page supports 1200 baud touch to nudge Arduino-style SAMD bootloaders into BOOT mode.

Notes
  • All operations occur locally in your browser. No data is uploaded.
  • Use Chromium-based browsers (Chrome, Edge) with Web Serial enabled.
  • Recommended baud in BOOT: 115200 or higher for speed.
